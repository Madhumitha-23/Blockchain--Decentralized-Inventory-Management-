# Decentralized Inventory Management DApp

## Overview

This project is a decentralized inventory management system built on the Ethereum blockchain. It allows warehouses to manage their inventory, track shipments, and handle returns using smart contracts.

## Features

- **Warehouse Registration**: Warehouses can register themselves.
- **Inventory Management**: Add, update, and remove inventory items.
- **Shipment Tracking**: Create and manage shipments.
- **Access Control**: Role-based access for admins and warehouse managers.

## Technologies Used

- **Solidity**: Smart contract programming language.
- **Truffle**: Development framework for Ethereum.
- **Web3.js**: JavaScript library for interacting with the Ethereum blockchain.
- **Ganache**: Local Ethereum blockchain for development and testing.
- **Infura**: Ethereum API for deploying to test and main networks.


### Prerequisites

- Node.js and npm installed
- Truffle installed globally
- Ganache installed for local development
